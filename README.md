# Money Printer Turbo

Free video generation studio: the LLM writes the script, Pexels provides the footage,
Edge TTS does the voiceover, FFmpeg renders the final video.

Set your API keys in **Settings → Repository secrets** as `PEXELS_API_KEY` and `KIMI_API_KEY`.
